# Color Palette

Base: Shadcn/UI Slate theme

## Light Mode

| Token | Hex | Usage |
|-------|-----|-------|
| --background | #ffffff | Page background |
| --foreground | #0f172a | Primary text |
| --primary | #0f172a | Buttons, links, emphasis |
| --primary-foreground | #f8fafc | Text on primary |
| --secondary | #f1f5f9 | Secondary buttons, subtle backgrounds |
| --secondary-foreground | #0f172a | Text on secondary |
| --muted | #f1f5f9 | Muted backgrounds, placeholders |
| --muted-foreground | #64748b | Secondary text, captions |
| --accent | #f1f5f9 | Hover states, highlights |
| --accent-foreground | #0f172a | Text on accent |
| --destructive | #ef4444 | Errors, destructive actions |
| --border | #e2e8f0 | Borders, dividers |
| --ring | #0f172a | Focus rings |

## Notes

- Slate palette chosen for neutrality and readability
- High contrast ratios (WCAG AA compliant)
- Dark mode uses deep blue-blacks for reduced eye strain
