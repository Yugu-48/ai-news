# Typography

## Font Stack

- **Sans**: Geist, system-ui, sans-serif (variable font)
- **Mono**: Geist Mono, monospace (variable font)

## Type Scale

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| H1 | 2.25rem (36px) | 700 | 1.2 | Page titles |
| H2 | 1.875rem (30px) | 600 | 1.3 | Section headers |
| H3 | 1.5rem (24px) | 600 | 1.4 | Subsection headers |
| H4 | 1.25rem (20px) | 600 | 1.4 | Card titles |
| Body | 1rem (16px) | 400 | 1.5 | Default text |
| Small | 0.875rem (14px) | 400 | 1.5 | Captions, metadata |
| Muted | 0.875rem (14px) | 400 | 1.5 | Secondary text |

## Notes

- Geist chosen for modern, clean aesthetic
- Variable font for performance and flexibility
- Consistent line heights for readability
- Weight hierarchy: 400 (body) → 600 (headings) → 700 (display)
